# Lista 1 — Exercício 1

Nesta pasta estão as versões do exercício de desenho de triângulos usando OpenGL.

Os arquivos mostram a mesma ideia usando modos diferentes de desenho:

- `a.cpp`: desenha dois triângulos preenchidos.
- `b.cpp`: desenha o contorno de dois triângulos.
- `c.cpp`: mostra os vértices dos dois triângulos como pontos.
- `d.cpp`: desenha um círculo aproximado por 100 pontos.

Os programas usam um VBO e um VAO para enviar as coordenadas dos vértices para a placa gráfica. A cor azul é enviada para o shader como uma variável uniforme.
