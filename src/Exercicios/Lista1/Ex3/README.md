# Lista 1 — Exercício 3

Neste exercício, o programa desenha um triângulo com uma cor diferente em cada vértice: vermelho, verde e azul.

O arquivo `main.cpp` guarda, para cada vértice, a posição e a cor. O vertex shader recebe esses dois atributos e repassa a cor para o fragment shader, criando a transição de cores dentro do triângulo.
