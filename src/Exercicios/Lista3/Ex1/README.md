# Lista 3 — Exercício 1

O programa permite criar triângulos na janela do OpenGL clicando com o botão esquerdo do mouse. Cada clique adiciona um vértice na posição do cursor e, a cada três vértices, um triângulo é formado.

Os triângulos completos são preenchidos com cores que se alternam. Enquanto um triângulo ainda está incompleto, os vértices já selecionados aparecem como pontos brancos.
